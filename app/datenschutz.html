Welche Daten werden gespeichert?

ABC Wort speichert ausschließlich folgende Daten lokal auf Ihrem Gerät (localStorage des Browsers):

▸ Gespeicherte Wörter (falls Sie die Speicherfunktion nutzen)

▸ Pro-Status (falls freigeschaltet)

▸ Farbschema-Einstellung (Hell/Dunkel)

▸ Anzahl der gespielten Runden (für die Probeversion)

Diese Daten verlassen Ihr Gerät niemals. Sie werden nicht an Server übertragen und nicht ausgewertet.

Server und Hosting

Die App wird über GitHub Pages (GitHub Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA) bereitgestellt. GitHub kann beim Aufruf der Seite technische Zugriffsdaten speichern (IP-Adresse, Zeitpunkt). Dies unterliegt der Datenschutzerklärung von GitHub.

Sprachausgabe (Text-to-Speech)

Die Aussprache-Funktion verwendet die Web Speech API Ihres Browsers. Die Verarbeitung erfolgt lokal auf Ihrem Gerät oder durch den Dienst Ihres Browser-Herstellers. Es werden keine Texte an unsere Server übertragen.

Cookies

Diese App verwendet keine Cookies.
